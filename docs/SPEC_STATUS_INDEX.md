# Spec Status Index

## Purpose

Track the current implementation status of spec and feature docs.

## Status Meanings

- `IMPLEMENTED`: Implemented in the current project.
- `PARTIALLY_IMPLEMENTED`: Some meaningful parts are implemented, but the spec is not complete.
- `NOT_IMPLEMENTED`: Not implemented in the current project.
- `HISTORICAL_REFERENCE`: Preserved for design history; not the canonical current contract.
- `SUPERSEDED`: Replaced by later direction or implementation decisions.
- `RESEARCH_ONLY`: Directional or exploratory spec, not a committed implementation target yet.
- `REVIEW_REQUIRED`: The document exists, but its status has not yet been
  verified against current source and tests.
