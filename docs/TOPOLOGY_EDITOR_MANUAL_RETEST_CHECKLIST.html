Topology Editor Manual Retest Checklist

Purpose: Targeted manual retest after topology editor changes and after review of the can-topology-editor-20260515 branch.

Test Setup

  • Launch: python -m tools.can_topology.can_top_editor
  • Primary profile: robot_2026_swerve
  • Suggested screen coverage: normal desktop width and maximized on a wide monitor
  • Record for each step: pass/fail, notes, screenshot path if needed

1. Load / Save / Restart

  • Launch the editor.
  • Load robot_2026_swerve.
  • Verify the expected large profile appears: 8 motors, 4 CANnect nodes, roboRIO, PDH, expected callouts and links.
  • Save the profile.
  • Quit the editor.
  • Relaunch the editor.
  • Reload robot_2026_swerve.
  • Verify nothing disappeared and no load exception occurred.

2. Fit / Zoom / Pan Stability

  • Use Fit to Window.
  • Verify the diagram is framed sensibly.
  • Click empty canvas and verify the viewport does not jump.
  • Zoom in with the scroll wheel.
  • Click empty canvas and verify zoom/view is preserved.
  • Pan with the middle mouse button.
  • Click empty canvas and verify the pan is preserved.

3. Selection Behavior

  • Select one node, then click empty canvas and verify selection clears.
  • Shift-select multiple nodes, then click empty canvas and verify all clear.
  • Select a bus segment, then click empty canvas and verify selection clears.

4. Wide-Screen Layout

  • Maximize on a wide display.
  • Use Fit to Window.
  • Verify the diagram is reasonably centered.
  • Verify content is not shoved hard left with excessive blank space on the right.
  • Verify important devices are not off-screen by default.

5. Bus Resize Behavior

  • Resize a bus segment left and right.
  • Verify attached normal devices follow the segment bounds.
  • Verify CANnect Direct and CANnect Inject nodes also follow the segment bounds.
  • Verify linked device connectors still line up.
  • Save, quit, reload, and verify the resized geometry is retained.

6. CANnect / Inject Behavior

  • Add one CANnect Direct node.
  • Add one CANnect Inject node.
  • Link a device to a CANnect node.
  • Add CAN bus links and set a CANnect port.
  • Save, quit, reload, and verify nodes, bus links, device links, and port assignment are retained.

7. Connection Filters

  • Click None.
  • Verify all connection types disappear.
  • Specifically verify the blue virtual/ethernet links disappear.
  • Re-enable CAN, Power, DIO, PWM, Analog, and Virtual one by one.
  • Verify each category displays only its expected links.

8. Component Editing and Retention

  • Edit one CAN motor device.
  • Edit one encoder device.
  • Edit the PDH device.
  • Edit one DIO device.
  • For at least one device, change label, CAN ID or DIO, vendor, device type, model, and tags.
  • Save, quit, reload, and verify edited values are retained exactly.

9. Validation Messaging

  • Create or edit a generic device so vendor and device type are missing.
  • Trigger save or validation.
  • Verify the error message names the exact device label.
  • If practical, also test one invalid DIO device.
  • Verify validation failures identify the offending configured entity clearly.

10. Callouts

  • Add or edit a callout.
  • Point one callout at a device.
  • If supported, point one callout at a bus.
  • Save, quit, reload, and verify text, target, and placement are retained.

11. Basic Edit Operations

  • Add a node.
  • Edit that node.
  • Remove that node.
  • If undo/redo is available, verify it works for at least one edit.
  • Save and reload.
  • Verify no exception occurs.

Highest-Priority Quick Pass

  • Load / save / quit / reload robot_2026_swerve.
  • Fit to Window then click empty canvas.
  • Middle-mouse pan then click empty canvas.
  • Resize a bus with CANnect/inject nodes present.
  • Use None filter and verify blue virtual links disappear.
  • Trigger invalid generic-device validation and verify the label appears in the error.
