# Historical Docs

## Purpose

Collect documentation that is no longer part of the current operator-facing doc set but is still useful for maintainer history, migration context, and design archaeology.

## What Belongs Here

- superseded feature specs for earlier design stages
- dated migration and checkpoint plans
- one-off refactor validation plans
- older manual procedures tied to a past repo state
- historical architecture drafts no longer treated as current guidance

## What Does Not Belong Here

- current operator workflows
- current setup and testing guidance
- current architecture and contract docs
- active feature specs that still define planned or implemented behavior
