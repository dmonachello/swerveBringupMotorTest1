# Feature spec workflow note

for new features I work in other programs or at least chatgpt to create a feature spec before involving codex
- I like to work through the language of the spec in english not any coding language
- I might do multiple passes on the spec between chatgpt and codex before finalizing it
- I force it to ask clarifying messages, even if they are annoying to answer, this way I can ensure that the feature is fully understood and I'm not missing any critical information that the model may assume or infer because it wil;l make assumptions and often they are not what you'd expect.
